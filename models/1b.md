# L20-1B-20B-Base

A 1,100,048,384-parameter English base model trained from random initialization
on one NVIDIA L20. The run also trained a new 32K byte-level BPE tokenizer and
used no third-party model weights for initialization.

## Release

- Weights: [AliceYin/L20-1B-20B-Base](https://huggingface.co/AliceYin/L20-1B-20B-Base)
- Evidence repository: private while continuation and post-training experiments remain active
- Training budget: 19,999,703,040 prediction tokens
- Context length: 2,048

## Measured result

| Measurement | Value | Boundary |
|---|---:|---|
| Final held-out loss | 2.4247146 | Fixed in-project validation protocol |
| Final held-out perplexity | 11.2990 | Same tokenizer/model only; not a cross-tokenizer ranking |
| Seven-task base macro | 51.2601% | HellaSwag, ARC-E/C, PIQA, WinoGrande, OpenBookQA, BoolQ |
| Six-task sensitivity macro | 49.9411% | BoolQ excluded because historical decontamination coverage was incomplete |
| Training throughput | 12,845 tok/s | Representative live snapshot at step 10,595 |
| Standard MFU | 71.17% | Point estimate using 132 BF16 TFLOP/s as denominator |

Under the frozen same-protocol comparison, the model exceeded TinyLlama's 1T
checkpoint by 1.0182 percentage points with a paired 95% bootstrap interval of
[+0.1584, +1.8860]. It was statistically tied with the tested 1.5T and 2T
checkpoints and lost to the tested 2.5T checkpoint.

This is not a global token-efficiency number-one claim. It applies only to the
frozen checkpoint set, task set, metrics, and harness protocol.

## Current research status

The 20B Base is frozen and public. A controlled continuation branch A was not
promoted after its evaluation failed to confirm an aggregate improvement.
Continuation B and the subsequent reasoning/SFT/preference/RLVR program remain
evidence-gated; post-trained scores must not be mixed into the base-model table.
