# L20-Edu-135M

An auditable 134.5M-parameter language-model study trained from scratch on one
NVIDIA L20. The released trajectory combines an initial 10B-token FineWeb-Edu
run with approximately 3B curated continuation tokens.

## Release

- Code and evidence: [yinli-systems/l20-edu-135m-pretrain](https://github.com/yinli-systems/l20-edu-135m-pretrain)
- Weights: [AliceYin/l20-edu-135m](https://huggingface.co/AliceYin/l20-edu-135m)
- License: MIT for the repository; consult the model and source-data cards for artifact-specific terms

## Selected result

The public checkpoint is the `stage4-sft-a0875` interpolation: 87.5% of the
anti-forgetting SFT candidate and 12.5% of the Stage 4 base candidate.

## Why it matters

The project preserves the decisions and failures that are usually missing from
small-model releases: data admission, continuation accounting, SFT retention,
an incomplete schedule-factorial experiment, and a negative GSM8K RLVR result.

It does **not** claim state of the art. Its six-task result is approximately
87.1% of the self-run SmolLM-135M mean while using about 2.17% of that model's
reported token budget. This is a bounded token-efficiency comparison, not a
universal capability ranking.
